## Principais correções aos vídeos

- A OpenAI **não** "se treina sozinha sem humanos": a automação acontece dentro de pesquisa dirigida por humanos.
- O acordo de testes mútuos OpenAI–Anthropic chegou ao contrato e foi **abandonado**.
- O Agent Sandbox da Alibaba cria **15 mil** sandboxes/min, não 100 mil.
- A "Standards Authority for Frontier AI" **não aparece** na proposta da OpenAI.
- A meta de pesquisador de IA automatizado até mar/2028 é de **out/2025**.
- A Anthropic fez **800 correções**, não "800 horas". O "Codebench" é o **CoBench 2.1 (55,8%)**.
